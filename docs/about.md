# About & Contributing

## About this site

This site is intended for anyone interested in Research Data Management (RDM) who is looking for a starting point into the topic. Its content is based on independent research into RDM fundamentals, cross-referenced with established teaching material such as [FDMatStudium.nrw](https://landesinitiativefdmnrw.github.io/FDMatStudium/thk/), a blended-learning RDM course developed by TH Köln and partners. Where relevant, each module also points to specific tools and standards used in practice, so that the general concepts introduced can be applied directly to catalysis research data.

The design and structure of this site follow [CoreMeta4Cat](https://nfdi4cat.github.io/CoreMeta4Cat/latest/), a metadata documentation site for catalysis research data.

## Contributing

Suggestions, corrections, and additions are welcome. Every page has an edit pencil next to its title that links directly to the GitHub editor for that file; changes can also be proposed through a pull request against the repository. Issues, such as an outdated link or a topic that deserves more detail, can be reported through the repository's issue tracker.
